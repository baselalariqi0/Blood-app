# متبرعو الدم — تطبيق أندرويد (React + Capacitor)

## تشغيل للتجربة على الحاسوب
    npm install
    npm run dev          # افتح الرابط الظاهر (على الجوال: نفس الشبكة)

## الحصول على APK (بدون تثبيت Android Studio)
1. ارفع هذا المجلد إلى مستودع GitHub جديد (فرع `main`).
2. تبويب **Actions** ← **Build APK** ← **Run workflow** (يعمل تلقائياً عند كل push).
3. بعد دقائق نزّل `blood-donors-debug-apk` من قسم **Artifacts**، فك الضغط، وانقل `app-debug.apk` للجوال وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

## البناء محلياً (يحتاج Android Studio وJDK 17)
    npm run build && npx cap add android && npx cap sync android && npx cap open android

## الربط بقاعدة بيانات حقيقية (اختياري)
    cd server && npm install && npm start      # SQLite في donors.db
ثم أنشئ ملف `.env` في جذر المشروع: `VITE_API_URL=http://<عنوان-الخادم>:3000` وأعد البناء.
على المحاكي استخدم `http://10.0.2.2:3000`. للإنتاج استخدم HTTPS وأضف مصادقة OTP قبل الحذف أو نشر الأرقام.

## الاختبار اليدوي
- فلتر الفصيلة + «المتاحون فقط» + البحث بـ «جدة».
- التسجيل ببيانات ناقصة أو عمر 17 (رسائل الخطأ)، ثم ببيانات صحيحة (يظهر في أعلى القائمة).
- فتح بطاقة متبرع وزر الاتصال، ثم «إلغاء تسجيلي».
